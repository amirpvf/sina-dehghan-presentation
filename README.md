# Dr. Sina Dehghan — interactive presentation

Persian, slide-style presentation (12 slides) for Dr. Sina Dehghan, pharmacist, served with GitHub Pages.

- `index.html` — the whole presentation in one file (fonts and images embedded, works offline)
- `resume/` — Persian and English resume PDFs offered for download inside the presentation

Keys: → / Space next, ← back, F full screen, N speaker notes, G all slides, click a photo to zoom.
